# Project Brief

BISHANA is a bike-share rider experience exploring a gesture-first interaction model, rider credentials, live ride telemetry, and a restrained light/dark visual system.

## Primary prototype goals
- Establish a coherent rider journey.
- Make core actions discoverable without depending on traditional navigation alone.
- Treat the rider credential as both identity object and interface surface.
- Connect brand identity, interface, and physical/digital mobility experience.
