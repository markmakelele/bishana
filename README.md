# BISHANA

Design/work repository for the BISHANA bike-share rider experience.

## Repository anatomy
- 00_BRIEF — project framing
- 01_RESEARCH — research and observations
- 02_SYSTEM — interaction and design system
- 03_IDENTITY — brand assets and rationale
- 04_USER_FLOWS — rider journeys
- 05_INTERFACE — interface specifications
- 06_PROTOTYPE — working prototype
- 07_TESTING — usability and iteration
- 08_DECISIONS — design decisions
- 09_CASE_STUDY — presentation narrative

See [WORKFLOW.md](WORKFLOW.md) for the project workflow.
